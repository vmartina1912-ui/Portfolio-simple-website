# Personal Portfolio Website

A simple personal portfolio website created using **HTML and CSS** as part of my web development learning journey.

## 🌐 About the Project

This is a basic two-page portfolio website designed to introduce myself and provide a way for visitors to get in touch with me.

### Pages

* **Home** – A brief introduction and overview about me.
* **Contact** – Contact information and a way for visitors to reach me.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Simple and clean design
* Two-page website
* Navigation between Home and Contact pages
* Basic CSS styling
* Responsive layout

## 🎯 Purpose

This project was created to practice the fundamentals of **HTML and CSS**, including webpage structure, styling, navigation, spacing, colors, borders, and layout.
